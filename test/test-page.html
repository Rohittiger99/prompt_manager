What to check

  • 1.
    Type // in any box below. The menu should appear at your cursor. Keep typing to filter, then press ↵.
  • 2.
    The draft test. Type a sentence, then //review at the end and pick the prompt. Your sentence must still be there, with the prompt inserted where the trigger was.
  • 3.
    The Escape test. Type //, press Esc, then type another letter. The menu must stay closed.
  • 4.
    The scroll test. Scroll down to the box at the bottom of this page and type //. The menu must appear at the cursor, not somewhere off-screen.
  • 5.
    Press Alt+K for the palette. ↵ inserts, Shift+↵ inserts and sends, Esc closes and returns focus to the box.
  • 6.
    The paste test. Pick //review and paste text.replace(/a/g, "$&!") into the Code field. The preview must show it unchanged.
  • 7.
    Highlight some prose on this page, then right-click and choose a modifier under OmniPrompt. Modifiers are also listed in the Alt+K palette.
