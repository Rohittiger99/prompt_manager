            Settings

            Changes save automatically.

            In the page

            Slash menu
            Type this in any text box to open your prompts.
            Search palette shortcut
            Opens search on any page. Click the box, then press your keys.
            Presets
            Alt+K
            Browser shortcut
            Also opens search. Set in Chrome. Default: Ctrl+Shift+K (Cmd+Shift+K on Mac).

            Library

            Starter pack
            Show one pack in the menu to keep it short. All packs are free.
            Priority
            Choose what gets priority at the top of every list.

            Website access

            Use OmniPrompt on every website
            Works on AI sites by default. Turn this on to use it in any text box, like Gmail or Slack. Chrome asks first. It only acts when you use it and never reads your chats.
            Enable a website
            Paste a link or domain to turn it on there, such as linear.app.

            Privacy

            Sites where OmniPrompt is off
            Turn it off on the sites you list. You can also do this from the popup.
            Remembered answers
            Short answers, like a tone, are remembered so forms start filled. Long text is never kept. Stays on this computer.

            Backup & sync

            Keep your library safe: sync it, restore a copy, or export a file.

            Sync

            Sync with your Chrome profile
            Off by default. Your prompts, favourites and settings follow your Chrome profile. Limit is about 100KB. For bigger libraries, use folder sync.
            Folder sync PRO
            Keep your library in a Dropbox, OneDrive, Google Drive or iCloud folder. Pick the same folder on each computer. No account, no size limit.
            Which folder?

            Pick your local sync folder, the one your cloud app already syncs on this computer. OmniPrompt saves one file there, omniprompt-library.json, and sends nothing over the internet.

            Google Drive: install Google Drive for Desktop first, then pick its folder.

            How it merges

            Syncs when this page opens and after each change. The newest edit wins. A restore point is saved before a deletion from another computer is applied.

            Restore points

            Automatic restore points
            A copy is saved once a day and before risky changes. The last 7 are kept on this computer. Uninstalling removes them, so export a file now and then.

              Import

              Import prompts
              Works with OmniPrompt files, JSON, AIPRM, CSV, Markdown, SKILL.md and plain text. Duplicates are skipped.

              Reset

              Restore built-ins or erase everything
              Restore the built-in library
              Undoes your edits to built-ins and brings back deleted ones.
              Erase everything
              Deletes all your prompts, favourites and settings from this browser. Cannot be undone. Export first.
