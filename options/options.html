The values you reuse for one client or project, filled in for you.

A workspace holds a name, a tone, a brief. Pick one and any field with the same name fills itself, in every prompt. A value called client_brief also fills {{@client-brief}}. Switch workspaces here, in the toolbar popup or from the Alt+K palette.

    Stepped chains PRO

    Prompts you use in order, one step at a time.

    For example research, then draft, then review. Start a chain from the slash menu, the palette or the popup. OmniPrompt inserts step 1, then waits. When you are ready, open the menu again and pick Next (or type //next). OmniPrompt never reads the AI's reply and never sends anything by itself.

      Stepped chains are part of OmniPrompt Pro. Existing chains are readable, exportable, and deletable on Free; editing and running require Pro.

            Appearance

            Theme
            For the popup, this page and the menus in the page. System follows your operating system and changes with it.

            Sync

            Sync with your Chrome profile
            Off by default, so everything stays on this computer. When on, your own prompts, folders, favourites and settings travel with your Chrome profile. Chrome allows about 100KB, so very large libraries stay local.
            Folder sync PRO
            Keep your library in a folder you choose, such as a Dropbox, OneDrive, Google Drive or iCloud Drive folder, and point OmniPrompt on your other computers at the same folder. OmniPrompt writes one file, omniprompt-library.json. There is no account and no server of ours; your cloud drive's own app moves the file.
            How to choose your cloud drive folder

            OmniPrompt reads and writes through your computer's local sync folder. It never asks for your cloud passwords, never connects to cloud APIs, and sends nothing over the internet.

            • OneDrive: Pick your local OneDrive folder (usually in your user directory, e.g. C:\Users\<You>\OneDrive on Windows or ~/OneDrive on Mac).
            • Google Drive: Requires Google Drive for Desktop set to "Stream files" (creates a virtual G:\ drive on Windows or a CloudStorage volume on Mac) or "Mirror files" (creates a local folder in your user directory). Choose that virtual drive or mirrored folder.
            • Dropbox: Pick your local Dropbox directory (usually C:\Users\<You>\Dropbox or ~/Dropbox).
            • iCloud Drive: On Mac, choose your iCloud Drive folder in Finder. On Windows, install iCloud for Windows and choose the local iCloud Drive folder.
            How it decides what wins

            OmniPrompt syncs when this page opens, after changes you make here, and when you press Sync now. Newer edits win, and a backup is taken before a deletion from another computer is applied. Settings stay per computer.

            Website access

            Use OmniPrompt on every website
            Out of the box, OmniPrompt works on AI chat sites. Turn this on to use // and Alt+K in any text box, such as Gmail, Slack, Jira or Docs. Chrome will ask you to allow access to all sites. OmniPrompt works offline and has no account. It only acts when you type // or use a shortcut. It never reads your chats and never sends your prompts to us. The only request it makes is licence activation, when you enter a Pro key.
            Enable a website
            Paste a link or domain (such as https://linear.app or mycompany.internal) to enable OmniPrompt there.

            Privacy

            Sites where OmniPrompt is off
            Add a hostname to silence the slash menu and the palette there. You can also switch the current site off from the toolbar popup.
            Remembered answers
            OmniPrompt remembers short answers, like a tone or a language, so a form starts where you left it. Long fields and anything filled from the page are never kept. They stay on this computer.

            Backup & import

            Your prompts never leave this browser unless you export or sync them.

            Backups

            Automatic backups
            OmniPrompt keeps a copy of your own prompts, edits and favourites once a day, and before any import that replaces your library. The last 7 are kept on this computer. Uninstalling the extension removes them, so download a file backup now and then.

              Import

              Import prompts
              Reads OmniPrompt backups, plain JSON lists, AIPRM exports, CSV or TSV with a header row, SKILL.md skill files, Markdown where each heading is a prompt, and plain text split on ---. Moving from Gemini Gems or custom GPTs? Paste their instructions into a text file and import it. Duplicates are skipped by title and template.

              Reset

              Restore the built-in library
              Undoes your edits to built-in prompts and brings back any you deleted.
              Erase everything
              Deletes your prompts, folders, favourites, usage history and settings from this browser. This cannot be undone. Export first.
